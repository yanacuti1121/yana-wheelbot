# Yana Wheelbot 섀시 — 출력 및 조립 가이드

([English](README.md) | [Tiếng Việt](README_vi.md) | 한국어)

이 문서는 아래 섀시를 다룹니다.

- [`yana-wheelbot-chassis-final.stl`](yana-wheelbot-chassis-final.stl): 슬라이서에
  불러올 파일입니다.
- [`yana_wheelbot_chassis_v2.scad`](yana_wheelbot_chassis_v2.scad): 치수를
  조정할 수 있는 OpenSCAD 소스입니다.
- 현재 STL 출력 크기: **210 x 122 x 43.85 mm**.

이 섀시는 ESP32-S3, 디스플레이, 오디오, 센서, 서보 4개, 배터리, 전원 보드
2개를 위한 마운트가 있는 기능성 통합 데크입니다. 아직 장식용 월-E 스타일
외장 쉘은 아닙니다.

> **중요:** 복제 PCB, 배터리, 스피커, 스위치, 서보 혼의 실제 치수는 판매
> 페이지 사진과 다를 수 있습니다. 최종 출력 전에 캘리퍼스로 실제 부품을
> 측정하고, 오차가 약 0.5 mm 이상이면 `.scad` 파일 상단의 변수를
> 수정하세요.

## 1. 출력 소재 선택

### 권장: 실사용에는 PETG

PETG는 로봇 본체 내부의 충격, 진동, 열을 PLA보다 잘 견딥니다. 서보를
탑재하는 섀시에는 가장 균형 잡힌 선택입니다.

0.4 mm 노즐 기준 시작 프로파일:

| 항목 | 시작 값 |
|---|---:|
| 레이어 높이 | 0.20 mm |
| 벽 두께 | 4 perimeter/wall |
| 상단/하단 | 5 레이어 이상 |
| 채움(infill) | 25–35% gyroid 또는 cubic |
| 노즐 온도 | 235–250 °C, 필라멘트에 따라 |
| 베드 온도 | 75–85 °C, 필라멘트에 따라 |
| 팬 | 30–50% |
| 브림 | 모서리가 들뜨면 5–8 mm |

### PLA/PLA+

출력이 쉽고 뒤틀림이 적어 시험 조립용으로 좋습니다. PLA로 만든 로봇을
자동차 안, 햇빛이 드는 창가, 열원 근처에 두지 마세요. 시작 프로파일:
노즐 205–220 °C, 베드 55–65 °C, 벽 4겹, 채움 25–30%.

### ASA/ABS

프린터가 밀폐형 챔버를 갖추고 있고 수축을 다루는 데 익숙한 경우에만
사용하세요. 자주 고온 환경에 놓이는 로봇에 적합합니다. ASA/ABS는
PETG/PLA보다 수축이 크므로 출력 후 포켓 치수를 다시 확인하세요.

### TPU

메인 데크나 서보 마운트에는 TPU를 사용하지 마세요. TPU는 타이어,
미끄럼 방지 패드, 진동 방지 발, 케이블 인서트를 출력하는 용도로만
적합합니다.

### 비권장

- 하중을 받는 마운트와 서보 장착부에 잘 깨지는 레진.
- 구조 부품에 실크 PLA.
- 벽 두께가 너무 얇은 출력; 서보는 장착부에 반복적인 진동 하중을
  줍니다.

## 2. 출력 방향과 서포트

1. 데크의 넓은 평면을 베드에 붙여서 놓습니다.
2. 섀시를 세워서 출력하지 마세요. 서보 마운트가 약해지고 서포트
   재료도 낭비됩니다.
3. 슬라이서가 긴 브릿지를 경고하면 TFT 베젤 부위에 한해 **빌드
   플레이트에서만** 서포트를 켭니다.
4. 특히 TFT 베젤, 배터리 배선 슬롯, 서보 마운트 부위의 레이어 미리보기를
   꼼꼼히 확인하세요.
5. PETG/ABS가 네 모서리에서 들뜨면 브림을 사용하세요.
6. 출력 후 서포트를 제거하고, 배선을 납땜하기 전에 각 부품을 먼저
   가조립해 보세요.

주요 마운팅 홀 4개는 지름 약 3.4 mm로 M3 관통 볼트에 맞춰져 있습니다.
PCB 포켓은 현재 보드별 마운팅 홀 패턴이 아니라 지지벽과 레일 방식을
사용합니다.

## 5. 필수 전원 아키텍처

```text
USB-C 5 V
    │
    ▼
TP4056 충전기 + 보호회로
    │ 보드 실제 표기에 따른 B+/B- 또는 OUT+/OUT-
    ▼
1S LiPo 3.0–4.2 V
    │
    ▼
ON/OFF 스위치
    │
    ▼
5 V 부스트(안정화)
    ├──────── ESP32-S3 5V/VIN 핀
    ├──────── MAX98357A VIN
    └──────── 서보 4개 VCC

ESP32-S3 3V3 핀
    ├──────── ST7735
    ├──────── INMP441
    ├──────── VL6180X
    └──────── TTP223

모든 GND는 공통으로 연결합니다.
```

안전 수칙:

- TP4056은 충전 회로이며, **부스트 컨버터가 아닙니다**.
- ESP32의 3V3 핀으로 서보에 전원을 공급하지 마세요.
- 3.7 V 배터리를 5 V 버스에 직접 연결하지 마세요.
- 3V3 핀에 5 V를 넣지 마세요.
- 부스트 컨버터는 서보 기동/스톨 시의 순간 최대 전류와 연속 전류를
  모두 감당해야 합니다.
- 2000 mAh 표기는 용량일 뿐, 방전 능력을 보장하지 않습니다.
- 초기 빌드에서는 충전 중 로봇 전원을 꺼두세요. 일반적인 TP4056은
  큰 부하를 구동하면서 동시에 충전하는 제대로 된 전원 경로/부하
  분배 기능이 없습니다.
- ESP32를 연결하기 전에 부스트 출력을 측정하세요. 전압이 5 V 근처로
  안정된 뒤에만 연결하세요.

## 6. 배선표

### ST7735

| ST7735 | ESP32-S3 |
|---|---|
| VCC | 3V3 |
| GND | GND |
| MOSI/SDA | GPIO11 |
| SCK/CLK | GPIO12 |
| DC/A0 | GPIO10 |
| CS | GPIO13 |
| RST/RES | GPIO14 |
| BL/LED | 아래 참고 |

Yana Wheelbot 펌웨어는 현재 **GPIO9**로 백라이트 밝기를 제어합니다.
백라이트 모듈이 GPIO가 안전하게 공급할 수 있는 전류보다 많이 소비한다면,
GPIO에서 백라이트 LED를 직접 끌지 말고 트랜지스터/MOSFET으로 구동하세요.
KST의 더 단순한 참고 배선은 BL을 3V3에 바로 연결하지만, 그러면
펌웨어로 밝기를 조절할 수 없습니다.

### INMP441

| INMP441 | ESP32-S3 |
|---|---|
| VDD | 3V3 |
| GND | GND |
| L/R | GND |
| WS | GPIO4 |
| SCK/BCLK | GPIO5 |
| SD | GPIO6 |

마이크 구멍을 바깥쪽으로 향하게 하고, 접착제가 음향 포트를 막지 않게
하세요.

### MAX98357A와 스피커

| MAX98357A | 연결 |
|---|---|
| VIN | 부스트에서 나오는 5 V 버스 |
| GND | 공통 GND |
| LRC/LRCLK | GPIO15 |
| BCLK | GPIO16 |
| DIN | GPIO17 |
| GAIN | 빌드 시트 설정에 따라 GND |
| SD | 빌드 시트 설정에 따라 VIN |
| SPK+ / SPK- | 스피커 양 단자 모두 연결 — 한쪽 단자를 GND에 묶지 말 것 |

### VL6180X

| VL6180X | ESP32-S3 |
|---|---|
| VIN/VCC | 3V3 |
| GND | GND |
| SDA | GPIO1 |
| SCL | GPIO2 |

### TTP223

| TTP223 | ESP32-S3 |
|---|---|
| VCC | 3V3 |
| GND | GND |
| OUT | GPIO7 |

### 서보

| 서보 | 신호 | 전원 |
|---|---:|---|
| 왼쪽 바퀴, 360° | GPIO47 | 5 V 서보 레일 + 공통 GND |
| 오른쪽 바퀴, 360° | GPIO45 | 5 V 서보 레일 + 공통 GND |
| 팔, 180° | GPIO20 | 5 V 서보 레일 + 공통 GND |
| 목, 180° | GPIO21 | 5 V 서보 레일 + 공통 GND |

서보 배선은 보통 갈색/검정이 GND, 빨강이 VCC, 주황/노랑/흰색이
신호선이지만, 실제 구매한 서보의 데이터시트나 라벨을 반드시
확인하세요.

### LED

| LED | GPIO |
|---|---:|
| 왼쪽 | GPIO3 |
| 오른쪽 | GPIO18 |

각 LED에는 반드시 자체 전류 제한 저항이 필요합니다. 저항 없이 GPIO에서
GND로 LED를 직접 연결하지 마세요. 고출력/고전류 LED는 트랜지스터
드라이버가 필요합니다.

### 사용하지 않는 핀

이 구성의 ESP32-S3 N16R8에서는 GPIO36과 GPIO37을 사용하지 마세요.
모듈의 PSRAM에 연결되어 있습니다.

## 7. 섀시 위 부품 배치

OpenSCAD 규칙: `+X`가 전면, `+Y`가 왼쪽입니다.

```text
                     전면 (+X)
              [ST7735 TFT 베젤]

 [ToF, 아래를 향함] [바퀴 서보] [ESP32-S3] [바퀴 서보]
 [마이크] [터치] [앰프] [부스트] [TP4056]
 [목 서보] [팔 서보] [배터리, 낮게] [스피커 + 그릴]

                     후면 (-X)
```

- 배터리는 낮게, 중앙 근처에 스트랩으로 고정합니다.
- ESP32의 USB-C 쪽은 계속 접근 가능하게 두고, 배터리·스피커 마그넷·
  부스트 컨버터에 안테나를 붙이지 마세요.
- 스피커는 그릴 위에 바로 안착시키고, 진동판이 바깥쪽으로 음을
  낼 수 있게 합니다.
- 마이크는 하울링/에코를 줄이기 위해 스피커·앰프에서 떨어뜨려
  둡니다.
- ToF 센서는 바로 아래를 향해 개구부를 통해 내다보며, 조기 엣지
  감지를 위해 바퀴 축보다 앞쪽에 위치합니다.
- TTP223은 얇은 플라스틱 층 뒤에 있어도 되며, PCB 자체가 노출될
  필요는 없습니다.
- 스위치는 케이블 타이나 작은 어댑터 플레이트를 이용해 범용 슬롯
  2곳에 장착합니다.
- LED는 정확한 패키지 크기를 아직 측정하지 못했기 때문에 고정
  소켓이 없습니다.

## 8. 기계 조립 순서

1. 섀시를 출력하고 서포트를 정리합니다.
2. 아직 납땜이나 접착 없이 모든 부품을 가조립해 봅니다.
3. 바퀴 서보 2개를 장착합니다. 축은 양쪽 모두 같은 높이로 바깥을
   향해야 합니다.
4. 혼/바퀴를 장착하고 손으로 돌려서 데크나 배선에 닿지 않는지
   확인합니다.
5. 팔 서보와 목 서보를 장착하고, 0–180° 전체 범위를 모두 점검합니다.
6. 베젤의 열린 쪽에서 TFT를 끼우되, 유리나 디스플레이 케이블에
   무리한 힘을 주지 않습니다.
7. 스피커를 링에 안착시키고 그릴을 향하게 하되, 진동판을 뚫지
   않습니다.
8. ToF 센서를 장착하고 아래쪽에서 들여다보아 광학 창이 플라스틱에
   가려지지 않는지 확인합니다.
9. ESP32를 장착하고 USB-C 쪽과 안테나 영역을 비워둡니다.
10. TP4056, 부스트 컨버터, MAX98357A, TTP223, INMP441을 각자의
    포켓에 장착합니다.
11. 스트랩을 슬롯 2곳에 통과시켜 배터리를 고정하되, 셀이 눌리지
    않도록 과하게 조이지 않습니다.
12. 전원 배선을 먼저, 신호 배선을 나중에 정리하고, 마이크 선은
    스피커·서보 배선에서 떨어뜨립니다.
13. 배터리 선, 스피커 선, 각 서보 리드에 스트레인 릴리프를
    추가합니다.
14. 풀로드 테스트를 통과한 뒤에만 외장을 닫습니다.

## 9. 전원 인가 및 테스트 순서

### A단계: 전원

1. 배터리 극성을 확인합니다.
2. 배터리를 보드 실제 표기에 따라 TP4056의 B+/B- 핀에 연결합니다.
3. 보호된 출력을 스위치를 거쳐 부스트 컨버터 입력에 연결합니다.
4. 아직 ESP32나 서보는 연결하지 않습니다.
5. 스위치를 켜고 부스트 출력을 측정합니다.
6. 보드에 트림 포텐셔미터가 있다면 대략 5 V로 조정합니다.
7. 전원을 끄고 5 V/GND 쇼트가 없는지 확인합니다.

### B단계: ESP32와 로직

1. ESP32의 5V/VIN 핀에 5 V를 공급합니다.
2. ESP32가 안정적으로 부팅되는지 확인합니다.
3. 3V3 레일을 측정합니다.
4. ST7735를 연결하고 디스플레이를 테스트합니다.
5. INMP441을 연결하고 마이크를 테스트합니다.
6. VL6180X를 연결하고 거리 값을 확인합니다.
7. TTP223을 연결하고 터치를 테스트합니다.

### C단계: 오디오와 서보

1. MAX98357A를 먼저 연결하고, 그 다음에만 스피커를 연결합니다.
2. 낮은 볼륨부터 테스트합니다.
3. 무거운 부하 없이 서보를 하나씩 테스트합니다.
4. 360° 서보 두 개의 정지 지점을 결정합니다.
5. 왼쪽 바퀴, 오른쪽 바퀴, 팔, 목 순서로 테스트합니다.
6. Wi-Fi, 디스플레이, 오디오가 함께 동작하는 상태에서 서보 4개를
   모두 동시에 실행하는 것은 마지막에 합니다.

서보 동작 중 ESP32가 리셋된다면, 펌웨어 버그로 단정하기 전에 부스트
컨버터, 배터리, 전선 굵기, 커넥터, 벌크 커패시터를 먼저 확인하세요.

## 10. Yana 펌웨어 빌드 및 플래시

가능하면 ESP-IDF 6.0.2를 사용하세요.

```sh
source /path/to/esp-idf/export.sh
idf.py --version
python3 scripts/build.py --list-boards
python3 scripts/build.py yana-wheelbot --name yana-wheelbot
```

이 문서의 하드웨어는 ST7735와 VL6180X를 사용합니다. `idf.py
menuconfig`의 **Yana Wheelbot** 항목에서 아래 두 옵션을 켠 뒤 다시
빌드하세요.

```text
CONFIG_YANA_WHEELBOT_DISPLAY_ST7735=y
CONFIG_YANA_WHEELBOT_TOF_VL6180X=y
```

설정을 바꾼 뒤:

```sh
idf.py fullclean
idf.py build
idf.py -p /dev/cu.usbmodemXXXX flash monitor
```

`/dev/cu.usbmodemXXXX`는 실제 시리얼 포트로 바꾸세요. 데이터 전송이
가능한 USB-C 케이블을 사용하세요. KST 펌웨어는 참고용일 뿐이며,
Yana 빌드는 항상 이 저장소의 소스에서 직접 빌드해야 합니다.

## 11. KST 참고 자료와 Yana 펌웨어 구분

KST의 공개 자료는 오직 **하드웨어 참고용**으로만 사용됩니다: 부품명,
GPIO, 5 V 전원 요구사항, 공통 GND, GPIO36/GPIO37 경고. 그들의
펌웨어, 가이드 문구, 마케팅 링크는 Yana에 복사되지 않습니다.

| KST 참고 항목 | 실제 Yana 동작 |
|---|---|
| 웹 플래셔, 병합 바이너리, `0x0` 오프셋 | Yana 펌웨어는 ESP-IDF로 소스에서 빌드하고 `idf.py`로 플래시합니다; KST의 오프셋은 Yana 빌드에 적용되지 않습니다 |
| `KST-Robot-Ai-xxxx` AP와 `/robot` 대시보드 | Yana의 공식 사양으로 취급하지 않습니다; Yana 펌웨어 자체의 프로비저닝 흐름과 `apps/controller-web`의 클라이언트를 사용합니다 |
| 전원 인가 시 TTP223을 약 5초간 눌러 Wi-Fi 변경 | **아직 Yana Wheelbot에 구현되지 않았습니다**; TTP223은 현재 더블탭으로 대화를 켜고 끄는 용도만 지원합니다 |
| `xiaozhi.me`에서의 활성화와 "Hi Lily" 웨이크워드 | 백엔드/설정에 따라 달라집니다; Yana 섀시나 보드의 고정 속성이 아닙니다 |
| ToF가 기본값으로 비활성화 | Yana는 현재 낙하 방지 센서를 기본값으로 **활성화**하며, 임계값 50 mm로 NVS에 저장합니다 |

Yana의 로컬 제어는 `ws://<IP>:8080/ws?token=<토큰>`의 WebSocket을
사용하며 페어링 토큰이 필요합니다. [controller-web](../../../../apps/controller-web/README.md)과
상위 폴더의 Yana Wheelbot 보드 문서를 참고하세요.

## 12. 바닥에서 주행하기 전 체크리스트

- [ ] 배터리가 부풀지 않고, 구멍이 없으며, 극성이 올바릅니다.
- [ ] TP4056이 보호회로가 있는 올바른 1S 타입입니다.
- [ ] 부하 상태에서 부스트 컨버터가 5 V 근처에서 안정적입니다.
- [ ] 5 V/GND 쇼트가 없습니다.
- [ ] 모든 GND가 공통으로 연결되어 있습니다.
- [ ] ESP32가 부팅되고 브라운아웃이 발생하지 않습니다.
- [ ] USB-C 포트에 계속 접근할 수 있습니다.
- [ ] ST7735가 올바른 방향으로 표시됩니다.
- [ ] 마이크가 선명하게 소리를 잡고, 포트에 접착제가 없습니다.
- [ ] 스피커에서 잡음이 없고, 진동판이 섀시에 닿지 않습니다.
- [ ] 바퀴 서보 2개가 정지 명령에 깔끔하게 멈춥니다.
- [ ] 좌/우 방향이 올바릅니다; 필요하면 리버스 보정을 적용합니다.
- [ ] 팔과 목이 이동 범위 양 끝에서 섀시에 부딪히지 않습니다.
- [ ] ToF 센서가 바로 아래를 향하고 플라스틱에 가려지지 않습니다.
- [ ] 낙하 방지 센서가 활성화되어 있고, 로봇을 손으로 들어 올려
      테스트해 보았습니다.
- [ ] 어떤 배선도 바퀴, 트랙, 혼에 닿지 않습니다.
- [ ] 유지보수를 위해 배터리, 전원 보드, ESP32를 분리할 수
      있습니다.
- [ ] 풀로드 상태에서도 ESP32가 리셋되지 않습니다.

## 13. 흔한 고장 증상

| 증상 | 먼저 확인할 것 |
|---|---|
| 서보 동작 중 ESP32가 리셋됨 | 부스트 용량 부족, 배터리 방전 능력 약함, 전선이 가늘음, 커넥터 헐거움, 벌크 커패시터 없음 |
| 정지 상태에서 서보가 떨림 | GND 공통이 아님, 노이즈 많은 전원, 신호선이 전원선 옆에 배선됨, 360° 서보 정지 지점이 어긋남 |
| 양쪽 바퀴가 반대 방향으로 구동됨 | `self.wheelbot.set_servo_reverse`를 사용하세요, 서보의 전원 리드를 바꾸지 마세요 |
| TFT가 흰색/검은색으로 표시됨 | ST7735/ST7789 빌드 옵션이 틀림, CS/DC/RST 배선이 틀림, BL에 전원이 안 들어감 |
| 소리가 나지 않음 | BCLK/LRC/DIN 배선이 틀림, MAX98357A에 5 V가 안 들어감, SPK+/SPK-가 반대로 연결됨 |
| 마이크 노이즈/하울링 | 마이크가 스피커에 너무 가까움, 마이크 선이 서보 옆에 배선됨, 스피커 볼륨이 너무 높음 |
| ToF가 항상 오류를 보고함 | SDA/SCL이 바뀜, 공통 GND 없음, 광학 창이 섀시에 가려짐, VL6180X 빌드 옵션이 꺼져 있음 |
| Wi-Fi가 약함 | ESP32 안테나가 배터리, 스피커 마그넷, 부스트 컨버터, 금속 물체에 붙어 있음 |
| 섀시 모서리가 휨 | 브림을 늘리고, 베드를 청소하고, 외풍을 줄이고, 베드 온도를 조정하세요 |
| 부품이 포켓에 맞지 않음 | 실제 보드를 다시 측정하고 `.scad` 파일의 envelope 값을 수정하세요 |

## 14. 유지보수

- 서보 나사, 혼, 배터리 스트랩을 주기적으로 점검하세요.
- JST 커넥터를 뺄 때 전선을 잡아당기지 말고 커넥터 하우징을
  잡으세요.
- 전원 배선을 작업하기 전에 배터리를 분리하세요.
- 부풀거나, 구멍이 나거나, 비정상적으로 뜨거운 셀은 절대 충전하지
  마세요.
- 충격을 받은 뒤에는 서보 마운트와 섀시 마운팅 홀 주변의 균열을
  확인하세요.
- 실제 부품 치수에 맞게 수정한 OpenSCAD 파일을 보관해서, 현재
  사용 중인 로봇 버전을 그대로 다시 출력할 수 있게 하세요.
